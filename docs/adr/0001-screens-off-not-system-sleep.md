# 1. Away means Screens Off, never System Sleep

The point of the app is to protect OLED monitors from burn-in and save power without losing the person's place. System Sleep would also turn off the camera and microphone, so the Mac could no longer notice the person returning or hear "Screen, wake up", and waking from it is slower. So Away turns every display off and keeps the Mac awake. Locking is off by default and a setting turns it on, because the person wants to come back to exactly where they left off.
