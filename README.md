# Proximity Mac

A macOS menu-bar app that turns your screens off when you walk away from the desk and back on when you return. It uses the built-in camera, with everything processed on the Mac. It never sends anything over the network, never saves a frame or a sound, and never puts the Mac to sleep.

Work in progress. See `docs/ARCHITECTURE.md` and the milestones in GitHub Issues.

Requires macOS 26 or later. Build and test with `swift build` and `scripts/test.sh`.
